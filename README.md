# 巡演舞台调度与走位编排工作台

面向剧院巡演团队的舞台执行工作台，覆盖演员与道具调度、舞台走位、执行提示、留言协同、版本回退、基线锁定和演出文档打印。

## 技术栈

Vue 3 + Element Plus + Pinia + Vue Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62044`。

## 核心工作流

- 在舞台平面图中选择走位，编辑入场点、退场点、路线节点和触发时机。
- 在同一脚本时间线中维护灯光、音响、道具与执行提示。
- 添加部门留言、标记问题并生成修改版本；撤销、重做和离线草稿会自动保存。
- 锁定演出基线，并从打印中心输出走位表和执行清单。

## 可恢复的换城批次

下一站装台前，舞台监督在「换城批次」页完成整条流水线：

1. **保存基线**：旧稿没有批次号时自动升级为「首版」，原路线与留言原样可查。
2. **定稿冻结**：新场馆宽深定稿时，上一城提示被引用为不可变冻结基线；锁定只改状态、不改文字，工作区进入只读。
3. **离线暂存**：模拟离线仅切换状态文字，走位与灯光音响提示的改动逐字段进入暂存队列。
4. **字段合并**：联网后按字段三路合并——单边改动自动采纳，两边都改的字段保留两版来源并置「冲突待裁决」。
5. **打印闸门**：存在未裁决冲突、未完成写入或未确认时，打印/导出一律禁用；确认后再改场馆尺寸或任一字段，出表签名变化、确认与出表自动失效重算。
6. **可恢复写入**：逐提示提交（MSW 服务端按 `批次号+提示号` 幂等），失败时整个批次保留为「写入失败」；继续只补未完成提示，重复继续不会多出基线。
7. **确认冻结**：全部写入后确认，冻结为新场馆演出基线，打印中心才出表。

批次、冻结基线、暂存队列均持久化在 localStorage，刷新后未完成批次与冻结锁自动恢复。
